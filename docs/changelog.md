## [v0.3.0] - 2026-10-15

### Highlights

- `@plexusone/host`: an application exports its pages as an `AppModule` and never imports a shell; a stack hosts it with its own `Shell` through `createHost`, and the same module runs on its own in `DevShell`
- `DevShell` and a development session run an application's interface with no backend
- `@plexusone/host/testing` renders an application as `createHost` would, for the application's own tests

### Upgrade Guide

- `@plexusone/host` is new at 0.3.0; it needs `@plexusone/shell` and `@plexusone/auth` 0.2.1 or later, React 19, and `react-router` 7 or 8. The other packages are unchanged

### Added

- `AppModule`, `AppContext`, `useAppContext` and `Shell` ([`05744c3`](https://github.com/plexusone/systemforge-web/commit/05744c3))
- `DevShell`, `devSession` and `devSessionClient` ([`ae98737`](https://github.com/plexusone/systemforge-web/commit/ae98737))
- `createHost`, `HostRoutes` and `HostSession`: the session, the router under `/orgs/:org`, choosing an organization, not-found and no-access pages, and the sign-in redirect ([`e296d1f`](https://github.com/plexusone/systemforge-web/commit/e296d1f))
- `renderApp` and `conformanceProblems` in `@plexusone/host/testing` ([`eebf56c`](https://github.com/plexusone/systemforge-web/commit/eebf56c))

### Documentation

- The `@plexusone/host` package page and a guide to writing an application ([`0866f1b`](https://github.com/plexusone/systemforge-web/commit/0866f1b))
- INIT-SYSTEMFORGEWEB-001 adds the app contract and hosting ([`9b2a53b`](https://github.com/plexusone/systemforge-web/commit/9b2a53b))

### Tests

- Hosting an example application in DevShell and, unchanged, in another stack's shell; routing, navigation, switching organizations and conformance ([`0f7a80e`](https://github.com/plexusone/systemforge-web/commit/0f7a80e))

## [v0.2.0] - 2026-10-15

### Highlights

- A session over the relying-party BFF in `@plexusone/auth`: `SessionProvider` and `useSession` read `/bff/session`, with memberships keyed by organization ID, a role per application, and the deployment's app catalog
- Shell chrome for composed applications: a product switcher from the app catalog, a controlled organization switcher, a session profile menu, named slots, and a light, dark and system theme
- Organization management pages and a chat package with AI SDK integration
- Packages are published under the `@plexusone` scope, publicly, and require React 19

### Upgrade Guide

- Import from `@plexusone/*` instead of `@systemforge/*`, and use React 19
- Pass Profile and Settings entries to `UserMenu` in `userActions` if you relied on the defaults
- For a SystemForge relying party, wrap the application in `SessionProvider` and pass `app`, `organizationId` and `onOrganizationChange` to `AppShell`

### Added

- `SessionProvider`, `useSession`, `SessionClient`, `toSession`, `membershipFor` and `organizationLabel` in `@plexusone/auth`; sign-in is a redirect to the BFF and sign-out a same-origin POST ([`f2f7adc`](https://github.com/plexusone/systemforge-web/commit/f2f7adc))
- `ProductSwitcher` and the `switcherApps` rule: the current application first, then the catalog applications the person holds a role in for the current organization ([`9916412`](https://github.com/plexusone/systemforge-web/commit/9916412))
- `OrganizationSwitcher`, a controlled organization picker keyed by organization ID ([`9807784`](https://github.com/plexusone/systemforge-web/commit/9807784))
- Named slots in `Navbar` and `AppShell`: `brand`, `command`, `actions`, with `app`, `organizationId` and `onOrganizationChange` turning on the switchers, and `breadcrumbs` passed through ([`1c2c10c`](https://github.com/plexusone/systemforge-web/commit/1c2c10c))
- `ProfileMenu`: who is signed in, the current organization and the role in this application, the application's `profileItems`, and sign out; the navbar uses it under `SessionProvider` ([`e72116b`](https://github.com/plexusone/systemforge-web/commit/e72116b))
- `useTheme`, `ThemeToggle`, `applyStoredTheme` and `showThemeToggle`: light, dark and system themes applied as the `dark` class, surviving unavailable storage ([`8509c3f`](https://github.com/plexusone/systemforge-web/commit/8509c3f))
