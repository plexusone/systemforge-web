# v0.4.0 Release Notes

**Release Date:** 2026-10-20

Adds `@plexusone/console` at 0.1.0, moves `@plexusone/host` to 0.4.0 and
`@plexusone/shell` to 0.2.4. The other packages are unchanged.

## Highlights

- **The organization console's pages.** `@plexusone/console` is an
  `AppModule` that lists an organization's connections to external services
  with their account, rotation and expiry, lets owners and admins test,
  replace, rename and disconnect them, and connects a new one through a
  gallery and a wizard built from the service's manifest. SystemAuth serves
  the build under `/console`. See [@plexusone/console](../packages/console.md).
- **Next steps for a connection.** `createConsoleApp({ nextSteps })` lets a
  host link a connection to the products that use it, after connecting and on
  each usable connection. The console links back to the application that sent
  the person, with `connection_id` on the return address so it can select the
  connection just made.
- **An application under a path.** `createHost`'s `basename` option roots the
  router at a path such as `/console`, so an application can share a host
  with others.
- **One product switcher everywhere.** The switcher lists applications in
  the catalog's `order` and highlights the current one in its place, instead
  of moving it first, so it looks the same in every application of a suite.
  An application the catalog does not list still comes first.
- **The sidebar and theme follow the person.** Each application runs on its
  own host, so its stored preferences are its own. Product switcher links now
  carry the sidebar state and theme as a URL fragment; the application they
  open adopts them before its first render and removes them from the address
  bar. `carryPreferences` and `adoptCarriedPreferences` are exported for links
  an application builds itself. See
  [Carrying the sidebar and theme](../packages/shell.md#carrying-the-sidebar-and-theme-between-applications).

## Requirements

- `@plexusone/console` needs `@plexusone/host` 0.4.0, `@plexusone/auth` and
  `@plexusone/ui`, React 19, and `react-router` 7 or 8.
- SystemAuth with the organization console, systemforge v0.18.0 or later,
  serves the console's pages and API.

## Installation

```bash
pnpm add @plexusone/console @plexusone/host @plexusone/auth @plexusone/ui react-router
```

## Upgrading

Install `@plexusone/host@^0.4.0` and `@plexusone/shell@^0.2.4`. Nothing
breaks, with one visible change: an application that relied on the current
product coming first in the switcher now shows it in the catalog's place. Give
the catalog entries an `order` to choose the sequence.

## Not in this release

- The console administers connections only; members, roles and access
  follow.
