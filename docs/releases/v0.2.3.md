# v0.2.3 Release Notes

**Release Date:** 2026-10-15

A fix release for `@plexusone/shell`. The other packages are unchanged.

## Fix

- **Navigation works without a `TenantProvider`.** Each sidebar item checked
  its roles through `useRoleCheck`, which throws outside a
  `TenantProvider`, so an application on `SessionProvider` alone could not
  pass `navigation` to `AppShell`. Items without `roles` now always show.
  Items with `roles` show when a `TenantProvider` can check them, and are
  hidden when none can; the application's API still enforces access.

## Upgrading

Install `@plexusone/shell@^0.2.3`.
