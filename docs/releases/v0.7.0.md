# v0.7.0 Release Notes

**Release Date:** 2026-11-03

`@plexusone/speech` 0.2.0 changes the speed or voice of speech while it
plays. The other packages are unchanged.

## Highlights

- **Change speed and voice while speaking.** The object `speak` returns,
  and `useSpeech`, have `setRate(rate)` and `setVoice(voice)`. Speech
  carries on with the new setting, as a video player's speed menu does,
  instead of stopping.
  - A browser can't change an utterance once it has started, so the one
    being spoken is cancelled and the rest of it is spoken from the last
    word reported to `onWord` (`trackWords` in `useSpeech`). Without
    `onWord`, that utterance is spoken again from its start: at most a
    sentence, or `maxChunkChars`.
  - The cancel is not reported as a stop: `done` still resolves once the
    speech ends.
  - Between utterances and while paused, the next utterance uses the new
    setting.

## Installation

```bash
pnpm add @plexusone/speech@^0.2.0
```

## Upgrading

Nothing changes for code written for 0.1.1. A speed or voice menu that
stopped speech and spoke again can call `setRate` or `setVoice` instead.
The standalone build's CDN address names the version: load
`@plexusone/speech@0.2.0/dist/speech.global.js`.
