# v0.3.1 Release Notes

**Release Date:** 2026-10-15

A fix release for `@plexusone/host`. The other packages are unchanged.

## Fix

- **`renderApp` works with pages that read the app context.** The
  `@plexusone/host` and `@plexusone/host/testing` entries were built as
  separate bundles, each with its own copy of the React context. A page's
  `useAppContext()` from `@plexusone/host` then threw inside `renderApp` from
  `@plexusone/host/testing`. The build now shares their common modules, and a
  test checks the built entries.

`createHost` in an application's own front end was not affected: it and the
application's pages both use the main entry.

## Upgrading

Install `@plexusone/host@^0.3.1`, and deprecate 0.3.0:

```bash
npm deprecate @plexusone/host@0.3.0 "testing entry has its own app context; use 0.3.1"
```
