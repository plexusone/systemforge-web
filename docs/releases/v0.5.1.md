# v0.5.1 Release Notes

**Release Date:** 2026-11-02

A security fix in `@plexusone/auth` 0.2.2. The other packages are unchanged.

## Highlights

- **Signing out ends the SystemAuth login session too.** Signing out ended
  the app's session at the BFF but left SystemAuth's login session, so the
  next sign-in resumed it without asking, and a person who signed out, for
  example on a shared computer, was signed straight back in. `signOut` and
  `logout` now ask the BFF for JSON; when it names SystemAuth's sign-out
  page, the provider submits a form there, and SystemAuth ends its login
  session, revokes the person's tokens, ends their sessions in the other
  apps and returns the browser signed out. See
  [Signing out of SystemAuth too](../packages/auth.md#signing-out-of-systemauth-too).

## Requirements

- systemforge v0.30.1 or later names SystemAuth's sign-out page. An older
  BFF answers `204`, and sign-out stays as before.
- SystemAuth lists the app's origin in `social_login.allowed_redirect_origins`.
- The app and SystemAuth share a site, such as `app.example.com` and
  `auth.example.com`: SystemAuth's login cookie is `SameSite=Lax`, so a
  browser does not send it on a cross-site `POST`.

## Installation

```bash
pnpm add @plexusone/auth@^0.2.2
```

## Upgrading

Nothing to change. `endSession` on `SessionProvider` or `AuthProvider`
replaces the form post, or `null` leaves it out.
