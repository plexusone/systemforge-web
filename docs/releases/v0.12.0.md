# v0.12.0 Release Notes

**Release Date:** 2026-11-25

The organization console's Connections page shows what each connection's check
found. Until now it showed only that the last check failed; now a member sees
when a connection was last checked and whether it worked, what it reaches, and
what its permissions allow, in the service's words. The other packages are
unchanged.

| Package              | Version   |
| -------------------- | --------- |
| `@plexusone/console` | 0.4.0     |
| every other package  | unchanged |

## Highlights

- **What each check found.** Each connection shows when it was last checked
  and whether it worked, what the check found it reaches, such as the
  properties a Search Console account can read (with "and N more" when the list
  was shortened), and what its permissions allow, from the service's scope
  descriptions.
- **Test says what it found.** Test reports "Working: it reaches 2
  properties." or why the check failed, instead of only that it ran.
- **`Detail`** is exported with the other types, for a host that renders its own
  connection list.

The release adds no breaking change.

## Requirements

SystemForge v0.32.1 or later, which requires connectforge v0.7.0, the version
that reports what a check found (`health.details`). Against an earlier one the
list shows the check line alone and no details.

See [@plexusone/console](../packages/console.md#pages).
