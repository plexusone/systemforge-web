# v0.2.2 Release Notes

**Release Date:** 2026-10-15

A fix release for `@plexusone/ui` and `@plexusone/chat`. The other packages
are unchanged at 0.2.1.

## Fixes

- **`@plexusone/ui` loads.** The package is `"type": "module"`, so its build
  writes ESM as `.js` and CommonJS as `.cjs`, but 0.2.1's exports named
  `.mjs` for import and the ESM `.js` for require. Neither loaded, and so
  `@plexusone/shell`, which depends on it, could not load either.
- **`@plexusone/chat`** no longer exports a `styles.css` that nothing builds.

## Upgrading

Install `@plexusone/ui@^0.2.2`. `@plexusone/shell` 0.2.1 accepts it through
its `^0.2.1` peer range, so no other package changes.

## Prevention

The build now checks that every package entry point loads: each `import`
target with `import()`, each `require` target with `require()`, and every
other target exists. CI runs it, so an export that names a missing or
wrongly typed file fails the build.
