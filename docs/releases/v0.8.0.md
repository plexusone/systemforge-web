# v0.8.0 Release Notes

**Release Date:** 2026-11-04

A security release across the packages. Navigation and redirects check
their URLs, the API client keeps requests under `baseUrl` and drops cached
data when the person or organization changes, and telemetry sends less
personal data by default.

| Package                 | Version | Package                | Version   |
| ----------------------- | ------- | ---------------------- | --------- |
| `@plexusone/api-client` | 0.3.0   | `@plexusone/pages`     | 0.3.0     |
| `@plexusone/auth`       | 0.3.0   | `@plexusone/shell`     | 0.3.0     |
| `@plexusone/chat`       | 0.3.0   | `@plexusone/speech`    | 0.2.1     |
| `@plexusone/console`    | 0.2.0   | `@plexusone/telemetry` | 0.3.0     |
| `@plexusone/host`       | 0.5.0   | `@plexusone/tenant`    | 0.3.0     |
| `@plexusone/invites`    | 0.1.1   | `design-tokens`, `ui`  | unchanged |

The release is breaking. Read [Upgrading](#upgrading) first.

## Highlights

- **Safe navigation.** `@plexusone/auth` adds `safeHref`, `sameOriginURL`,
  `returnPath` and `navigateTo`. Every link and redirect the packages follow
  outside React goes through them, since `location.assign('javascript:…')`
  runs script and React's `href` check does not cover it. The console's
  return address after connecting a service, the login page's
  `redirectUrl` and the sign-in `return_to` stay on this site.
- **API client.** A request path is appended to `baseUrl`, never resolved
  against it, so a path can no longer send a request and its headers to
  another host. When the person signs out or switches account, or the
  organization changes, the query cache is reset, so the next person never
  sees the previous one's data. `ApiProvider` follows the organization
  `@plexusone/tenant` selects.
- **Organization-scoped roles.** `ProtectedRoute` and `hasRole` check roles
  in the organization `orgId` names, not in any membership.
- **Telemetry privacy.** Page views send the path without its query string;
  title and the referrer's origin are opt-in. Errors are scrubbed of URL
  queries, emails and tokens. Clicks are named by a label the page chooses.
  Requests carry cookies only to the page's own origin. The ProductGraph
  anonymous ID is created with the first event and persisted only with
  consent.
- **Chat.** A closed widget no longer holds a focused input that could send
  what is typed elsewhere on the page, and the stream parser no longer
  loses text split across network chunks.
- **Release hygiene.** Published source maps no longer name the build
  machine's paths, and the build fails if they would.

## Installation

```bash
pnpm add @plexusone/auth@^0.3.0 @plexusone/api-client@^0.3.0
```

Install the packages you use at the versions above, together: `shell`,
`tenant`, `pages`, `host` and `console` need `@plexusone/auth` 0.3.0.

## Upgrading

- **`ApiClient` paths.** Remove a `baseUrl` prefix you repeated in paths
  (`/api/users` under `baseUrl: '/api'` is now `/api/api/users`). Encode IDs
  you put in paths with `encodeURIComponent`. A path with a scheme, host,
  backslash or `..` segment throws.
- **Role checks.** Pass `orgId` to `ProtectedRoute` and `hasRole`, or use
  `RequireRole` from `@plexusone/tenant`. Without `orgId`, a person with
  several memberships is refused.
- **Sign-out.** If the server keeps the session, `logout` leaves the person
  signed in and sets `error`; show it.
- **Login redirect.** `redirectUrl` must be on this site; anything else goes
  to `/`.
- **User settings.** Pass `onSaveProfile` to keep the profile editable, and
  `onChangeAvatar` to show Change avatar.
- **Telemetry.** Set `collectTitle`, `collectReferrer`,
  `credentials: 'include'` or `persistAnonymousId` (with consent) only if
  you need them, and send ProductGraph events through a same-origin route
  that adds the API key.
- **Chat.** Pass `autoFocus` to a `ChatComposer` that should take focus,
  and `composer={false}` to a `ChatThread` you pair with one.
- **Host.** Gate `devSession` on `import.meta.env.DEV`; it is ignored in a
  production build.
- **Server.** Run SystemForge v0.31.0 or later. The organization pages show
  admin controls only to owners, which that release enforces.

The earlier `@plexusone/host` 0.3.1 and 0.4.0 and `@plexusone/speech` 0.1.1
and 0.2.0 are replaced by these versions.
