# v0.6.1 Release Notes

**Release Date:** 2026-11-02

`@plexusone/speech` 0.1.1, the build v0.6.0 describes. The other packages
are unchanged apart from how they are published.

## Highlights

- **`@plexusone/speech` 0.1.1 has everything in v0.6.0.** 0.1.0 on npm was
  published from a build of an earlier commit and is now deprecated. It
  works, but it lacks v0.6.0's last changes:
  - words are marked with the punctuation around them, and a dash can be
    reported as a word;
  - dictation on Chrome for Android repeats each partial result;
  - in Safari, a word with punctuation inside it, such as "don't" or
    "3.5", is cut short;
  - the main and React entry points each have their own copy of the
    speaking code, so `stopSpeaking()` cannot stop speech started by
    `useSpeech`.

- **Publishing rebuilds each package.** Every package's `prepublishOnly`
  script runs its build, so `pnpm publish` uploads a build of the commit
  being published.

## Installation

```bash
pnpm add @plexusone/speech@^0.1.1
```

## Upgrading

Move from 0.1.0 to 0.1.1; nothing else changes. The standalone build's
CDN address names the version, so a page that loads
`@plexusone/speech@0.1.0/dist/speech.global.js` should load `@0.1.1`.
