# v0.9.0 Release Notes

**Release Date:** 2026-11-05

A new package, `@plexusone/login-card`: a manager prints or downloads a
login card for someone they manage, such as a child, and that person signs
in by holding the card up to the camera. The other packages are unchanged.

| Package                 | Version   |
| ----------------------- | --------- |
| `@plexusone/login-card` | 0.1.0     |
| every other package     | unchanged |

## Highlights

- **The code as a QR code.** A SystemAuth login code, and only a login
  code, drawn as a QR code in alphanumeric mode. Any other value, such as a
  web address, is refused.
- **Cards to print or save.** A credit-card-sized card with the name, an
  optional picture, when it stops working, where to use it and the code in
  groups of four for typing. Printed one per card-sized page or several on
  Letter or A4, or saved as SVG or a 300 dpi PNG, all drawn in the browser.
- **Camera sign-in.** `startLoginCodeScanner` reads a card with the
  device's camera, on the device: `BarcodeDetector` where the browser has
  it, jsQR elsewhere, loaded only when scanning starts. Other QR codes are
  ignored, and the camera stops on a code, when closed and when idle. It
  needs no framework, so a game can use it; `LoginCodeScanner` is the
  React component, with plain-language messages when the camera cannot
  start and a way to type the code instead.

The release adds no breaking change.

See [@plexusone/login-card](../packages/login-card.md).
