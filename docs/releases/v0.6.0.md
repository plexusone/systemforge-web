# v0.6.0 Release Notes

**Release Date:** 2026-11-02

Adds `@plexusone/speech` at 0.1.0. The other packages are unchanged.

## Highlights

- **Read aloud and dictate with the browser's own speech.** `speak` reads
  text or segments with pauses between them, and `listen` turns speech into
  text as it is recognized. Both use the Web Speech API, so there is no
  service, key or cost. See [@plexusone/speech](../packages/speech.md).
- **Speech that keeps working in Chrome.** Long text is split into short
  utterances, because some voices stop partway through a long one. New
  speech clears the queue first, and an utterance that the browser accepts
  but never starts is retried once, then reported as `start-timeout`.
  Pausing never uses the browser's pause, which can stall speech in every
  page; it repeats at most the interrupted sentence on resume.
- **Word highlighting.** `onWord` reports each word as it is spoken, as
  offsets into the text passed to `speak`, without the punctuation around
  it. `useSpeech({ trackWords: true })` keeps the current word in `word`.
  Tested on macOS in Chromium, Safari and Edge. Not every voice reports
  words; with one that does not, speech plays without the mark.
- **For React, and for pages without a build step.** `useSpeech`,
  `useListen` and `useVoices` are in `@plexusone/speech/react`.
  `@plexusone/speech/browser` is one file defining `window.PlexusSpeech`,
  for a script tag or a Go program that embeds its pages.
- **A guide.** [Adding read-aloud and voice input](../guides/read-aloud.md)
  covers a read-aloud control, highlighting, what to show when speech does
  not start, a voice picker, dictation and testing.

## Requirements

- A browser with the Web Speech API. Speech synthesis is in every current
  browser; speech recognition is in Chrome, Edge and Safari.
- React 19 for `@plexusone/speech/react` only. The main entry point has no
  dependencies.

## Installation

```bash
pnpm add @plexusone/speech
```

## Upgrading

Nothing to change: no existing package moved.

## Not in this release

- Recorded or generated audio. The package speaks with the voices the
  browser has; an application that needs one voice everywhere should play
  recordings.
- Word marks for voices that report no words.
