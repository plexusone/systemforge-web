# v0.2.1 Release Notes

**Release Date:** 2026-10-15

A packaging release with no code changes from v0.2.0.

## Changes

- Every package has a README on npm, and `homepage`, `repository` and `bugs`
  links to its documentation, source and issues.
- v0.2.1 is the first version published for every package. Of v0.2.0, only
  `@plexusone/api-client` was published.

## Upgrading

Use `^0.2.1` for `@plexusone/*`. The code and APIs are those of
[v0.2.0](v0.2.0.md).
