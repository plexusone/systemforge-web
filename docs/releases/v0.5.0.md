# v0.5.0 Release Notes

**Release Date:** 2026-10-26

Adds `@plexusone/invites` at 0.1.0. The other packages are unchanged.

## Highlights

- **Pages for launching invite-only.** `@plexusone/invites` gives an
  application the two pages SystemForge's invite-gated sign-up needs.
  `InviteAdminPage` lets platform administrators create invite codes with a
  use limit and expiry, invite people by email address, invite people from
  the waitlist, set how many people each member may invite, and see who
  joined with which invite. `InvitePeoplePage` lets a member create invite
  links from their allowance and revoke ones nobody has used. See
  [@plexusone/invites](../packages/invites.md).
- **Shown once.** SystemForge stores only a hash of each code, so a new code
  or link is shown once, with a copy button, and the page says so.
- **A typed client.** `createInvitesApi` covers every route of SystemForge's
  invite API, with snake_case wire types as the API sends them and
  `ApiError` carrying the HTTP status and the API's message.
- **A guide.** [Adding invite pages](../guides/invite-gated-signup.md) covers
  where to serve the invite API, styles, routes, which menu links to show to
  whom, and testing.

## Requirements

- `@plexusone/invites` needs `@plexusone/ui` and React 19.
- systemforge v0.22.0 or later serves the invite API (`signupapi`), behind
  the application's own session with `Service.SignupAPI` or on the SystemAuth
  host with `Options.SignupAPI`.

## Installation

```bash
pnpm add @plexusone/invites @plexusone/ui
```

Add the package's built files to Tailwind's sources:

```css
@source "../node_modules/@plexusone/invites/dist";
```

## Upgrading

Nothing to change: no existing package moved.

## Not in this release

- Nothing is emailed. Operators and members share invite links themselves.
