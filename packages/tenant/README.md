# @plexusone/tenant

Multi-tenant context for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/tenant @plexusone/auth
```

Requires `@plexusone/auth`, `react`, `react-dom`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/tenant/) for usage and the API reference.
