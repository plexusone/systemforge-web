# @plexusone/api-client

Type-safe API client with OpenAPI integration for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/api-client
```

Requires `react`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/api-client/) for usage and the API reference.
