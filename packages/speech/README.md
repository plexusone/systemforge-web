# @plexusone/speech

Text-to-speech and speech-to-text with the browser's own speech, with React
hooks and a standalone build for pages without a build step.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), web
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/speech
```

React is needed only for `@plexusone/speech/react`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/speech/) for usage and the API reference.
