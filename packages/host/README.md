# @plexusone/host

Host SystemForge applications: the app and shell contracts, `createHost`, and
a standalone `DevShell`.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/host @plexusone/auth @plexusone/shell react-router
```

Requires `react` 19 and `react-router` 7 or 8.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/host/) for usage and the API reference.
