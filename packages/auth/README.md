# @plexusone/auth

Authentication primitives for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/auth
```

Requires `react`, `react-dom`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/auth/) for usage and the API reference.
