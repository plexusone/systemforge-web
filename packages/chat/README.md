# @plexusone/chat

Chat UI components for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/chat
```

Requires `react`, `react-dom`.

## Documentation

See the [SystemForge Web documentation](https://plexusone.github.io/systemforge-web/) for usage.
