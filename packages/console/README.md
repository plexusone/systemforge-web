# @plexusone/console

The SystemForge organization console: an organization's connections to
external services, connected step by step from each service's manifest.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/console @plexusone/host @plexusone/auth @plexusone/ui react-router
```

Requires `react` 19 and `react-router` 7 or 8.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/console/) for usage and the API reference.
