# @plexusone/pages

Standard page components for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/pages @plexusone/auth
```

Requires `react`, `@plexusone/auth`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/pages/) for usage and the API reference.
