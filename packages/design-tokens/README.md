# @plexusone/design-tokens

Design tokens and CSS custom properties for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/design-tokens
```

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/design-tokens/) for usage and the API reference.
