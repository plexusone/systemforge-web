# @plexusone/telemetry

Telemetry, error tracking, and performance monitoring for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/telemetry
```

Requires `react`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/telemetry/) for usage and the API reference.
