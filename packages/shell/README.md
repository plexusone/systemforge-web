# @plexusone/shell

Application shell components for SystemForge applications.

Part of [SystemForge Web](https://github.com/plexusone/systemforge-web), React
packages for applications built on the
[SystemForge](https://github.com/plexusone/systemforge) platform.

## Install

```bash
pnpm add @plexusone/shell @plexusone/auth @plexusone/tenant @plexusone/ui
```

Requires `react`, `@plexusone/auth`, `@plexusone/tenant`, `@plexusone/ui`.

## Documentation

See the [documentation](https://plexusone.github.io/systemforge-web/packages/shell/) for usage and the API reference.
